# 🧀 Catch the Cheese

> A fun arcade-style mini game built with HTML, CSS, and JavaScript.

Control Jerry, catch the cheese, avoid the bombs, and survive as long as you can!

## 🕹️ How to Play

- ⬅️ Arrow Left → Move Left  
- ➡️ Arrow Right → Move Right  
- 📱 Swipe (on mobile) to move  

### Rules:
- Catch 🧀 cheese to earn points.
- Avoid 💣 bombs.
- Missing a cheese = Game Over.
- Catching a bomb = Game Over.

- Smooth slow starting speed

## 🎯 Game Logic

- 75% probability of cheese spawn
- 25% probability of bomb spawn
- Speed increases every 5 points
- Game ends on:
  - Missing cheese
  - Catching bomb
